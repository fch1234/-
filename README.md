# 数字长征 · 互动地图（H5）

华南师范大学 2026 年主题团日竞赛活动（秋季）· 计算机学院 2025 级网络工程 1 班团支部
子活动三「数字长征」的落地产品。**一个 HTML 文件，无框架、无后端、无网络请求。**

---

## 一、它长什么样

三个界面：

1. **封面** — 深色，「数字长征 / e 路向党 · 青春挺膺」，点「开始重走」进入。
2. **路线图** — 竖屏手绘风长征路线，7 个节点按 1934.10 → 1936.10 连成一条曲线。
   未点亮的节点是空心灰圈，已点亮变金色，路线随进度由红虚线变红实线。
3. **海报** — 7 关全点亮后生成 1080×1560 的「我的长征足迹」海报，可保存转发。

**玩法（也是班会/运动会现场可以演示的部分）：**
点一个发光的节点 → 弹出 200 字史实 → 答 1 道党史题 → 答对才点亮 → 下一关解锁。
7 关走完自动生成海报。

题库 24 道（17 道长征程史实 + 7 道二十大/新时代成就），每关随机抽 1 道、7 关不重复，
所以不同的人同一部手机重走，抽到的题不一样。

---

## 二、怎么打开

**最简单：双击 `index.html`**，用 Chrome / Edge / Safari 打开即可，不需要装任何东西、不需要联网。

想在手机上看：把这个文件夹拷到手机（或用微信「文件传输助手」发给自己），
用手机浏览器打开 `index.html`。微信里直接打开 html 会提示用其他应用打开，选浏览器即可。

## 三、怎么给别人扫（答辩现场）

三种方式，按省事程度排：

1. **GitHub Pages**（免费、有固定网址，推荐）
   - 新建仓库 → 上传本文件夹里所有文件（注意保持目录结构）→ Settings → Pages →
     Source 选 `main` / root → 等 1 分钟，得到 `https://用户名.github.io/仓库名/`
   - 把这个网址生成二维码（微信搜「二维码生成」小程序即可），印在展板/PPT 上。

2. **学院/支部自己的服务器或对象存储**（如果学院给空间）：把整个文件夹传上去，拿到的地址同样能扫码。

3. **直接发文件**（最省事，但对方要手动用浏览器打开）：微信发 `数字长征H5.zip` 或直接发 `index.html`。

> 二维码建议放在 PPT 的 P10 或 P11 那个虚线框里——那里本来就留了「二维码」占位。

## 四、怎么换成你们自己的照片

1. 在 `数字长征H5/` 下建一个 `images/` 文件夹（已经建好了）。
2. 把现场照片放进去，命名随意，例如 `01.jpg`、`ruijin.jpg`。
   建议：**宽度 800–1200px、竖构图 4:3 或 3:4、单张 < 300KB**（手机拍的原图直接放也行，就是加载慢一点）。
3. 打开 `index.html`，搜索 `nodes: [`，给对应节点加一个 `img` 字段：

```js
{ code:"01", name:"瑞金出发", date:"1934.10", place:"江西 瑞金 · 于都",
  x:316, y:356, lb:"b", de:1,
  img:"images/01.jpg",          // ← 加这一行
  story:"..." },
```

没加 `img` 的节点会显示「影像位」虚线框，不影响使用。

## 五、怎么改文字 / 题目 / 支部名

全部集中在 `<script>` 顶部的 `DATA` 对象里，改完保存、刷新即可，不用重新打包。

| 改什么 | 改哪里 |
|---|---|
| 支部名（页脚/海报） | `DATA.branch`、`DATA.branchFull` |
| 口号 | `DATA.slogan` |
| 7 个节点的名字、日期、地点、200 字史实 | `DATA.nodes[]` 的 `name` / `date` / `place` / `story` |
| 24 道题 | `DATA.quiz[]`，格式 `{q:"题干", o:["A","B","C","D"], a:正确项下标, e:"解析"}`，`a:0` 表示第一个选项 |
| 节点位置 | `nodes[]` 里的 `x` / `y`（画布 375×450 的坐标系，`lb` 控制标签朝向：b下 bl左下 r右 l左 t上） |

**注意**：题一定要是 24 道、每道 4 个选项，否则「7 关不重复抽题」的逻辑会出错。

## 六、答辩彩排用的两个开关

- `index.html?skip=3` — 直接点亮前 3 关，用于演示「已走一半」的状态。
- `index.html?skip=7&poster=1` — 全部点亮并直接弹出海报，用于演示最终成果。
- 页面右上角「重走」= 清空进度重来（进度存在浏览器 localStorage，key 是 `szcz_v1`）。

## 七、已知限制（提前说清楚，别现场翻车）

- **海报保存**：微信内置浏览器不支持 `download`，要提示用户「长按图片保存到相册」；
  手机浏览器/电脑上点「保存图片」直接下载。
- **字体**：正文用系统字体（PingFang SC / 微软雅黑），没有外链字体，所以断网也能正常显示。
- **无后端**：没有访问统计。PPT 里的「1,286 人次访问」要么接统计工具（如百度统计），
  要么按现场扫码数手填。
- **iOS Safari 无痕模式**：localStorage 可能不可写，进度不保存，但不影响走完流程。
